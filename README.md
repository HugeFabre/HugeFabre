## 🧭 Cómo trabajo como Tech Lead · Agentic Developer

</div>

Soy **Tech Lead**, **Engineering Manager** y **Agentic Developer**, con **más de 10 años** construyendo software para retail y eCommerce. Coordino un equipo multidisciplinario para múltiples productos — aplicaciones **Android**, **iOS** y **web**, más **cloud** — y meto agentes y copilotos al flujo del equipo. El rol no es solo escribir código: es alinear gente, sacar versiones y que móvil, web, API y cloud hablen el mismo idioma.

- APIs .NET detrás de las apps.
