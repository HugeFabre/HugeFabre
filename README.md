## 🧭 Cómo trabajo como Tech Lead · Agentic Developer

</div>

Soy **Tech Lead** y **Agentic Developer**: coordino un equipo multidisciplinario de desarrollo para múltiples productos — aplicaciones **Android**, **iOS** y **web**, más **cloud** — y meto agentes y copilotos al flujo de trabajo del equipo. El rol no es solo escribir código: es alinear al equipo, sacar versiones y que móvil, web, API y cloud hablen el mismo idioma.

<table align="center">
<tr>
<td valign="top" width="33%">

**Android**

- Apps Kotlin / Compose en piso y almacén.
- Cobro en terminales SUNMI, con o sin red.
- Inventario (barras y RFID), surtido y verificación.

</td>
<td valign="top" width="33%">

**iOS y web**

- Apps iOS en Swift para el mismo ecosistema de producto.
- Aplicaciones web: facturación, dashboards y backoffice.
- Conectores de eCommerce y canales digitales.

</td>
<td valign="top" width="34%">

**Cloud**

- **GCP**, **Vercel** y **Fly.io**.
- APIs .NET detrás de las apps.
- Linear para priorizar el trabajo del equipo.
- Agentes, MCP y reglas para copilotos (`ai-specs`).
- Azure en la trayectoria DevOps.

</td>
</tr>
</table>
